## Installation
### 1. Clone the repository
```bash
git clone https://github.com/paulSuman005/Express_typescript_starter_app.git <Project-name>
```
### 2. Go to the project directory
```bash
cd <Project-name>
```
### 3. Install dependencies
```bash
npm install
```

### 4. Create a new .env file in the root directory and add the PORT env variable
```
echo PORT=3005 >> .env 
```

### 5. Run the project
```bash
npm run dev
```
